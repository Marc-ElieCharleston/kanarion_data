# Thème et message

## Le thème (propriétaire, 2026-10-03)

Le jeu montre **les mauvais choix des humains et leurs conséquences**, sur soi-même et bien
au-delà. Les Fissures représentent le mal dans le monde, la perversion. Il faut voir des gens qui
choisissent bien (**pardon, amour**) et d'autres qui choisissent mal (**rancune, vengeance**).

## Le message par des versets modifiés

Le propriétaire veut faire passer un message en intégrant des **versets bibliques reformulés**
(quêtes, livres, etc.). Le lore est une allégorie chrétienne gardée universelle : la Parole, le
Souffle (Neshamah), X, l'Imitateur, les panoplies aux noms hébreux.

Règles (`kanarion_lore/Kanarion_Narrative_Design_Foundation.txt`) :
- ne jamais prêcher, suggérer ;
- le joueur découvre, il ne reçoit pas la morale ;
- universel, jamais confessionnel ;
- les monstres ne sont pas le mal, ils sont corrompus (on les combat pour délivrer) ;
- pas de manichéisme ;
- le gameplay prime, le message soutient.

Et (audit de cohérence) : pas de texte qui désigne le porteur comme « juste ».

## Où placer les versets

| Où | Comment |
|---|---|
| Livres d'histoire | une épigraphe en tête de chaque livre |
| Bestiaire | la dernière ligne de la fiche (palier 100) |
| Quêtes à choix | le verset arrive **après** le choix, en écho |
| Murmures | courts, ambigus (on ne sait pas qui parle) |
| Objets, panoplies | la description |

## Les compteurs cachés

**Compassion / rancune** (décidé 2026-10-03, remplace compassion / sévérité). Invisibles, jamais
affichés ; au niveau 60 ils suggèrent une faction, sans verrou.

## X à chaque moment clé

À chaque blessure et à chaque choix, X dit une phrase de compassion, **quel que soit le choix**. Elle
peut changer selon le choix, elle ne juge jamais. Voir l'épilogue « Le Message » : « Être pardonné
n'efface pas la responsabilité. Mais être aimé change tout. »
