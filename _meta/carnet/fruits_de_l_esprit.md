# Les fruits de l'Esprit (histoires de lumière)

Statut : proposition (2026-10-03).

## Pourquoi

Le propriétaire (2026-10-03) : le jeu devient sombre (les Dorn, Harlan, Lisa, Bastien) ; il faut
aussi **des gens qui portent les fruits de l'Esprit, et qu'on aide**.

**Règle proposée : pour chaque histoire sombre, une histoire lumineuse pas loin.** Plus courtes, plus
légères, parfois drôles ; on aide, on répare, on voit le bien grandir. Elles referment les Fissures
au lieu d'en ouvrir (voir [fissures.md](fissures.md)).

Fruits (Galates 5:22) : amour, joie, paix, patience, bonté, bénignité, fidélité, douceur, maîtrise de
soi.

## Lieux qui guérissent

- **Le hameau de la forêt** : si le joueur l'a défendu (trahison d'Harlan), il y revient pour une
  **fête** : le feu rallumé, les familles, les enfants.
- La ferme des Dorn (Prairie), selon les choix.
